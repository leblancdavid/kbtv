## Broadcast Core

The control room and studio remain the key gameplay pair.

Preserve these ideas:

- Studio sits near the control room rather than elsewhere in the station.
- The player should understand that the control room is the broadcast control point.
- A soundproof window into the studio is important enough to call out explicitly.
- Control-room props include desk, computer, soundboard, phoneboard, audio cabinet, shelves, and office chair.
- Studio props include Vern, desk, mic / mic stand, studio speakers, and bookshelf / prop areas.

## Circulation Read

The rough layout suggests a useful live-show route structure:

- Control room to studio is the shortest, most important broadcast route.
- Control room to equipment room requires moving north through or near the studio-side area.
- Control room to kitchen / break room and bathroom requires leaving the main console zone and moving east/southeast.
- Lobby, front desk, parking lot, backyard, toolshed, walkway, and roof ladder create future event and expansion hooks.

This is a strong direction because it keeps the broadcast core compact while letting errands pull the player into less safe spaces.

## Gameplay Strengths

- The station has a clear front-of-house area: lobby, front desk, parking lot.
- The station has a clear back-of-house area: backyard, toolshed, walkway, roof ladder.
- Equipment, documents, supplies, and bathroom are separate enough to support different errand types.
- The control room / studio pair can support both normal broadcast work and paranormal window scares.
- Exterior hooks support suspicious van, antenna, cryptid, and roof events later.

## Review Concerns

- Exact dimensions are not ready for implementation; treat all shapes as proportions and adjacency only.
- Door openings need explicit labels before greyboxing so we know which paths are intended.
- The detailed control-room/studio sketch is separate from the full station sketch, so it should be treated as a prop-placement reference, not a second competing floorplan.
- The control-room console position needs to be marked as the player's primary idle/work position.
- The studio window should be represented in the full station layout, not only in the detail sketch.
- If the equipment room is directly above the studio, verify that the route creates risk without becoming too long or confusing.
- The kitchen / break room and bathroom appear far enough from the console to create risk, but route timing must be tested in greybox.
