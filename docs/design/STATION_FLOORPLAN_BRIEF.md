# KBTV Station Floorplan Brief

## Purpose

Define what the KBTV station layout must accomplish before it becomes a 3D greybox.

The level should support the current broadcast-management loop while making the station feel like a haunted, late-night workplace where stepping away from the console is useful, risky, and readable.

## Design Pillars

- Control room as home base
- Studio as visible pressure space
- Errands that create time risk
- Paranormal activity staged in readable places
- Compact local-radio station scale
- Expansion-ready layout for later rooms

## Required First-Pass Spaces

| Space | Role | Notes |
|-------|------|-------|
| Control Room | Primary player workspace | Contains console, caller screening, queue management, ad controls, monitors |
| Studio | Vern's broadcast room | Visible from control room; locked during live shows except door drop-offs |
| Equipment Room | Maintenance route | Forces the player away from the console and past a meaningful sightline |
| Kitchen / Supply Area | Vern needs route | Coffee, food, cigarettes, water, whiskey, and other consumables |
| Bathroom | Short errand / scare space | Useful for quiet scares, mirror events, and route tension |
| Main Hallway | Circulation spine | Connects work zones without feeling like an office maze |
| Entrance / Lobby | Future visitor events | Staging for suspicious guests, agents, fans, or intruders |
| Back / Exterior Access | Antenna and field events | Future access to transmitter, parking lot, or rooftop equipment |

The first greybox can include only control room, studio, equipment room, kitchen/supply, bathroom, and hallway if scope needs to stay small.

## Core Spatial Relationships

- Control room should connect directly to the studio through a windowed boundary or adjacent door.
- Studio should sit north of the control room unless a later floorplan explicitly changes the established orientation.
- Equipment room should require the player to pass or lose sight of the studio window.
- Supply area should be close enough for frequent need-management errands but far enough to make the console unattended.
- Bathroom should be optional in normal flow but valuable for supernatural events.
- Hallway should support quick navigation without hiding every destination behind turns.

## Target Route Timing

Assume first-person walking speed will be tuned later. Floorplan review should use rough timing targets:

| Route | Target Round Trip |
|-------|-------------------|
| Console to studio door drop-off | 8-12 seconds |
| Console to kitchen/supply | 12-18 seconds |
| Console to equipment room | 18-25 seconds |
| Console to bathroom | 10-18 seconds |
| Console to entrance/lobby | 18-30 seconds |

Routes longer than 30 seconds should be reserved for high-stakes events or future station expansion.

## Visibility Goals

- Player should be able to see the studio window from the control room console or from a nearby monitoring position.
- A route to equipment should create at least one moment where the studio is visible but the console is not.
- A route to supplies should create at least one moment where the console is not visible.
- Paranormal events should sometimes happen at the edge of vision, not only in rooms the player enters.

## Risk Model

Leaving the console can create risk through:

- Missed incoming callers
- Caller patience loss
- Bad ad-break timing
- Vern's needs worsening
- Equipment malfunction escalation
- Paranormal activity progressing while unattended

The layout should make the player ask: "Can I afford this errand right now?"

## Paranormal Event Zones

Plan at least these event zones:

| Zone | Example Events | Design Need |
|------|----------------|-------------|
| Studio Window | Figure behind Vern, object movement, cold breath | Visible tension while player is working |
| Equipment Room | Flickering rack, phone tap, signal intrusion | Maintenance pressure and audio-system stakes |
| Hallway | Shadow crossing, distant footsteps, door movement | Route interruption without complex props |
| Bathroom | Mirror event, faucet static, apparition | Optional scare room with tight framing |
| Entrance / Lobby | Suspicious van sightline, visitor knocking, agent entry | Future external-threat staging |
| Back Access | Antenna noise, creature scrape, exterior light | Future outdoor expansion hook |

## First-Pass Acceptance Checklist

Before greyboxing, the floorplan should answer:

- Where is the player's exact primary console position?
- What can the player see from the console?
- How does the player deliver items to Vern without entering the studio during live shows?
- What errand most often pulls the player away from the console?
- What is the shortest risky route?
- What is the longest normal route?
- Where can an event happen while the player is screening a caller?
- Where can an event happen while the player is fetching supplies?
- Which doors are locked, unlocked, or context-sensitive during a live show?
- Which rooms are required now and which are expansion hooks?

## Initial Layout Hypothesis

Start with this relationship, then iterate in Excalidraw:

```text
          Back / Exterior Access
                   |
             Equipment Room
                   |
Kitchen ---- Hallway ---- Bathroom
                   |
             Control Room
                   |
          Studio Window / Door
                   |
                Studio
```

This is not a final map. It is a starting structure that preserves the current control-room/studio pairing while adding route pressure.
